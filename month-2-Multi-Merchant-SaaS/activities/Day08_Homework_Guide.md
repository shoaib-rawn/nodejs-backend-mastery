This guide contains step-by-step instructions and code explanations to complete the Day 08 verification challenge.

## Step 1: Create the Verification Script

Create the file [activities/verify-day08.ts](file:///d:/anti/month-2-Multi-Merchant-SaaS/activities/verify-day08.ts) and add the following verification logic:

```typescript
import { PrismaClient } from '@prisma/client';
import { env } from '../src/config/env';
import { comparePassword } from '../src/utils/password';

const prisma = new PrismaClient();

async function runTests() {
  console.log('🧪 Starting Day 08 security checks...\n');

  // =================================================================
  // TEST 1: ZOD TYPE CASTING VERIFICATION
  // =================================================================
  console.log('--- Test 1: Verifying Zod Type Casting ---');
  console.log(`Port value: ${env.PORT}`);
  console.log(`Port data type: ${typeof env.PORT}`);

  if (typeof env.PORT === 'number') {
    console.log('✅ Test 1 Passed! env.PORT was successfully cast to a number.\n');
  } else {
    console.log('❌ Test 1 Failed! env.PORT is still a string.\n');
  }

  // =================================================================
  // TEST 2: BCRYPT HASH SIGNATURE VERIFICATION
  // =================================================================
  console.log('--- Test 2: Verifying Password Hash Signature ---');
  const adminUser = await prisma.user.findUnique({
    where: { email: 'admin@platform.com' }
  });

  if (adminUser) {
    const passwordHash = adminUser.password;
    console.log(`Loaded password string: "${passwordHash}"`);
    console.log(`Hash length: ${passwordHash.length} characters`);
    
    // Check if the hash starts with standard bcrypt prefixes
    const hasCorrectSignature = passwordHash.startsWith('$2a$') || passwordHash.startsWith('$2b$');
    const hasCorrectLength = passwordHash.length === 60;

    if (hasCorrectSignature && hasCorrectLength) {
      console.log('✅ Test 2 Passed! Database contains a secure 60-character bcrypt hash signature.\n');
    } else {
      console.log('❌ Test 2 Failed! The password is not correctly hashed.\n');
    }

    // =================================================================
    // TEST 3: PASSWORD COMPARISON LOGIC
    // =================================================================
    console.log('--- Test 3: Verifying Password Comparison ---');
    const isPasswordCorrect = await comparePassword('adminpassword123', passwordHash);
    console.log(`Password match result: ${isPasswordCorrect}`);

    if (isPasswordCorrect) {
      console.log('✅ Test 3 Passed! The plain text password matches the database hash.\n');
    } else {
      console.log('❌ Test 3 Failed! Comparison function returned incorrect result.\n');
    }
  } else {
    console.log('❌ Tests failed because admin user was not found. Make sure to run seeding first!\n');
  }
}

runTests()
  .catch((err) => console.error('❌ Tests crashed:', err))
  .finally(async () => await prisma.$disconnect());
```

## Code & Logic Explanation

Let's break down the technical code syntax used in this guide:

### 1. Zod String to Number Coercion
```typescript
PORT: z.coerce.number().default(5000)
```
*   **`z.coerce.number()`**: Environment variables stored in `.env` are always read as raw strings by Node.js. If you specify `PORT=5000` in `.env`, `process.env.PORT` is `"5000"` (a string). `z.coerce.number()` forces Zod to convert `"5000"` to `5000` (a number) before validating and exporting it.

### 2. Bcrypt Hash Format
```typescript
passwordHash.startsWith('$2a$') || passwordHash.startsWith('$2b$')
```
*   **Bcrypt Signature:** Every hash generated by Bcrypt follows a strict, standardized signature structure:
    *   `$2a$` or `$2b$`: Identifies the schema version of the algorithm used.
    *   `12`: The salt rounds/cost factor (after the version separator).
    *   The remaining characters consist of the generated salt and the encrypted password digest.
    *   The total length of the resulting hash string is always exactly `60` characters.

### 3. Password Verification (`bcrypt.compare`)
```typescript
return bcrypt.compare(password, hash);
```
*   **`bcrypt.compare()`**: You **cannot** decrypt a bcrypt hash to see what the password was. Instead, when a user logs in, we pass their plain text input and the stored database hash to `bcrypt.compare`. The algorithm extracts the salt from the stored hash, hashes the user's input using that salt, and checks if the resulting digest matches the stored hash.
