## Step 1: Create the Verification Script

Create a new file in your workspace under the path [activities/verify-seed.ts](file:///d:/anti/month-2-Multi-Merchant-SaaS/activities/verify-seed.ts) and add the following verification code:

```typescript
import { PrismaClient } from '@prisma/client';

// 1. Initialize the Prisma Client to connect to our PostgreSQL database
const prisma = new PrismaClient();

async function verify() {
  console.log('🧪 Starting database verification...\n');

  // =================================================================
  // TEST 1: MULTI-TENANCY ISOLATION (STORE COUNT)
  // =================================================================
  console.log('--- Test 1: Verifying Multi-Tenant Store Count ---');
  const stores = await prisma.store.findMany({
    select: { id: true, name: true, slug: true }
  });
  console.log(`Successfully found ${stores.length} stores in database:`);
  stores.forEach(s => console.log(` - [ID: ${s.id}] Store Name: "${s.name}" (Slug: ${s.slug})`));
  console.log(stores.length === 3 ? '✅ Test 1 Passed!\n' : '❌ Test 1 Failed!\n');


  // =================================================================
  // TEST 2: SELF-REFERENTIAL 1:N CATEGORIES (HIERARCHY)
  // =================================================================
  console.log('--- Test 2: Verifying Self-Referential Category Tree ---');
  const laptopCategory = await prisma.category.findFirst({
    where: { name: 'Laptops' },
    include: {
      parent: true // Eagerly loads the parent Category record
    }
  });

  if (laptopCategory) {
    console.log(`Category: "${laptopCategory.name}"`);
    console.log(`Parent Category ID: ${laptopCategory.parentId}`);
    if (laptopCategory.parent) {
      console.log(`Parent Category Name: "${laptopCategory.parent.name}"`);
      console.log(laptopCategory.parent.name === 'Electronics' ? '✅ Test 2 Passed!\n' : '❌ Test 2 Failed!\n');
    } else {
      console.log('❌ Test 2 Failed: No parent category found!\n');
    }
  } else {
    console.log('❌ Test 2 Failed: "Laptops" category not found!\n');
  }


  // =================================================================
  // TEST 3: SELF-REFERENTIAL N:M PRODUCTS (RECOMMENDATIONS)
  // =================================================================
  console.log('--- Test 3: Verifying Related Product Recommendations ---');
  const macbookProduct = await prisma.product.findFirst({
    where: { name: { contains: 'MacBook' } },
    include: {
      relatedTo: {
        include: {
          relatedProduct: true // Loads the related Product records mapped in the junction
        }
      }
    }
  });

  if (macbookProduct) {
    console.log(`Product: "${macbookProduct.name}"`);
    console.log('Related recommendations seeded:');
    macbookProduct.relatedTo.forEach(rel => {
      console.log(` - Recommended Product: "${rel.relatedProduct.name}" ($${rel.relatedProduct.price})`);
    });

    const hasMouse = macbookProduct.relatedTo.some(rel => rel.relatedProduct.name.includes('MX Master'));
    console.log(hasMouse ? '✅ Test 3 Passed!\n' : '❌ Test 3 Failed!\n');
  } else {
    console.log('❌ Test 3 Failed: MacBook not found!\n');
  }


  // =================================================================
  // TEST 4: STORE-SCOPED SEQUENCES
  // =================================================================
  console.log('--- Test 4: Verifying Store-Scoped Order Sequences ---');
  const firstOrders = await prisma.order.findMany({
    where: { orderNumber: 1 },
    include: {
      store: true // Eagerly load the tenant store metadata
    }
  });

  console.log(`Found ${firstOrders.length} orders registered with Order Number #1:`);
  firstOrders.forEach(o => {
    console.log(` - Order ID: ${o.id} belongs to Store: "${o.store.name}" (Total: $${o.totalAmount})`);
  });

  // Verify that sequence number #1 exists in multiple different store accounts
  const uniqueStores = new Set(firstOrders.map(o => o.storeId));
  console.log(uniqueStores.size >= 2 ? '✅ Test 4 Passed!\n' : '❌ Test 4 Failed!\n');
}

verify()
  .catch((err) => {
    console.error('❌ Verification script crashed:', err);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

## Syntax & Code Explanation

Let's break down the technical syntax and database queries used in this script:

### 1. The Prisma Import & Client Instantiation
```typescript
import { PrismaClient } from '@prisma/client';
const prisma = new PrismaClient();
```
*   **`PrismaClient`**: The auto-generated class generated by Prisma compiled from your `schema.prisma`. It contains query APIs custom-tailored to your exact models.
*   **`const prisma = new PrismaClient()`**: Instantiates the client. It automatically manages connection pooling to PostgreSQL.

### 2. Selection Query (Test 1)
```typescript
const stores = await prisma.store.findMany({
  select: { id: true, name: true, slug: true }
});
```
*   **`findMany`**: Query operator that returns all matching rows from the `Store` table as an array of objects.
*   **`select`**: Projection object. By specifying columns as `true`, we instruct Prisma to only request `id`, `name`, and `slug` from the database. Unspecified columns are excluded, saving network bandwidth.

### 3. Fetching Nested Self-Referential Records (Test 2)
```typescript
const laptopCategory = await prisma.category.findFirst({
  where: { name: 'Laptops' },
  include: { parent: true }
});
```
*   **`findFirst`**: Queries the table and returns the first row matching the filter.
*   **`where: { name: 'Laptops' }`**: Relational filtering.
*   **`include: { parent: true }`**: Triggers a relational join. Under the hood, Prisma queries the Category table and joins the row where `parentId` matches `Category.id`, populating the `parent` property on the returned object.

### 4. Fetching N:M Self-Referential Junctions (Test 3)
```typescript
include: {
  relatedTo: {
    include: {
      relatedProduct: true
    }
  }
}
```
*   **Nested `include`**: Because related products share an N:M relation, we query the `relatedTo` junction table, and then instruct Prisma to perform a second join inside the junction to load the destination `relatedProduct` attributes.
