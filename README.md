# 🚀 Node.js Backend Engineering Mastery Roadmap

Welcome to my **Backend Engineering Portfolio**! This repository showcases production-grade backend projects built during a 4-Month intensive Node.js roadmap covering REST APIs, Relational Databases (PostgreSQL/Prisma), Web Security, Caching (Redis), Containerization (Docker), Real-Time Systems (WebSockets), and AI integrations.

## 🛠️ Tech Stack & Skills Covered

- **Backend Runtimes:** Node.js, Express.js, TypeScript
- **Databases & ORMs:** PostgreSQL (with pgvector), MongoDB, Prisma ORM, Mongoose
- **Security & Auth:** JWT (Access + Refresh tokens), bcryptjs, Helmet, CORS, RBAC
- **Performance & Caching:** Redis Caching, Rate Limiting, Database Indexing
- **Real-Time & Workers:** WebSockets (Socket.io), BullMQ Background Processing, Docker
- **AI Integrations:** OpenAI API, Vector Search Embeddings (Cosine Similarity)
- **Testing & Docs:** Jest, Supertest, Swagger / OpenAPI
